# 🔥 Featured Projects

### 🎓 [EduRisk](https://github.com/ShrijalDubey/EduRisk)

**AI-Powered Student Performance & Risk Prediction**

A full-stack academic intelligence platform for managing student records and predicting academic risk.

Features include:

* 🔐 JWT authentication
* 👨‍🎓 Student management
* 📚 Course & enrollment management
* 📊 Attendance & assessment analytics
* 📈 Academic dashboards
* 🤖 ML-based risk prediction
* 💾 PostgreSQL persistence

The prediction pipeline uses **Logistic Regression + StandardScaler** with features such as attendance, marks, assignment completion, GPA, failed subjects, internal marks and study hours.

**Stack:** React • FastAPI • PostgreSQL • SQLAlchemy • scikit-learn • Pandas • NumPy

---

### 🌱 [AgriSmart](https://github.com/ShrijalDubey/AgriSmart)

**AI-Powered Smart Agriculture Platform — SIH 2026**

An AI-driven agriculture system built for **Smart India Hackathon 2026**.

The platform combines:

* 🌿 Plant disease detection
* 🌍 Soil intelligence
* 🌦️ Weather intelligence
* 🤖 AI farming assistant
* 🌾 Crop-related insights
* 🗺️ Location-based agricultural data
* 📊 Farm and plot management

Architecture:

`React → FastAPI → ML / AI Services → SQLite + MongoDB`

The disease detection pipeline uses **PyTorch + EfficientNet-B0**, while soil intelligence uses **SoilGrids** and weather intelligence uses **Open-Meteo**.

**Stack:** React • FastAPI • PyTorch • EfficientNet • MongoDB • SQLite • Gemini • scikit-learn
