## 🚀 Featured Projects

### 🐋 [DockTer](https://github.com/ShrijalDubey/DockTer) — AI Dockerfile Generator & Local Orchestrator

An intelligent, full-stack application that scans codebases, auto-detects dependencies, and generates secure, production-ready Dockerfiles, `docker-compose.yml` assets, and GitHub Action workflows using Groq LLM inference.

* **Key Features:**
  * **Repository Analyzer:** Auto-detects frameworks (`package.json`, `requirements.txt`, etc.)
  * **Interactive Editor:** Split-screen layout featuring a Monaco Editor with directory navigation trees
  * **1-Click Local Deploy:** Connects with a local companion agent daemon to automatically deploy and run containers locally
  * **SSE Logs Console:** Streams container stdout/stderr in real-time using Server-Sent Events (SSE)
* **Tech Stack:** React 19, Vite, CSS Modules, FastAPI, Python, Groq LLM API, GitPython, Docker Engine API, SQLite, SQLAlchemy


### 📈 [Atlo](https://github.com/ShrijalDubey/Atlo) — GitHub Repo Health & Dependency Visualizer

A FastAPI + React tool that visualizes GitHub repo dependency graphs, maps issues to files, and surfaces repo health signals to help contributors and maintainers understand a codebase at a glance.

* **Tech Stack:** React, FastAPI, Python, Graph visualization
